# Volumix

Микшер громкости приложений для Windows 10/11 в стиле Windows 11 (аналог Volumey).

## Возможности

- Громкость и отключение звука для каждого приложения, общая громкость, индикаторы уровня
- Выбор устройства вывода (становится устройством по умолчанию в Windows)
- Значок в трее: левый клик — компактный микшер, правый — меню
- Кнопки Spotify в трее: «назад», «пауза/играть», «вперёд» отдельными значками рядом с часами (пока открыт Spotify)
- Глобальные горячие клавиши: громче / тише / без звука для активного окна, конкретного приложения или общей громкости; открыть микшер; следующее устройство вывода
- Всплывающий индикатор громкости при нажатии горячих клавиш
- Автозапуск с Windows (запуск сразу в трей), светлая / тёмная / системная тема, Mica и Acrylic
- Голосовые команды на русском (Win+Alt+V или кнопка микрофона), без интернета: «спотифай на пятьдесят»,
  «дискорд потише», «выключи звук», «переключи на наушники», «тёмная тема», «включи автозапуск», «открой настройки»

## Голосовое управление

Распознавание — [Vosk](https://alphacephei.com/vosk/) с моделью `vosk-model-small-ru-0.22` (лежит в `models\`,
`build.ps1` скачивает её сам). Звук идёт в два распознавателя: свободный (обычные слова и падежи) и с грамматикой
из слов команд и названий запущенных программ (названий вроде «спотифай» нет в словаре модели, поэтому они
раскладываются на известные кусочки). Побеждает вариант, который парсер понял лучше.
Модель загружается при первой команде (~1 с) и выгружается через 3 минуты простоя.

- `Services/VoiceService.cs` — микрофон и распознавание
- `Services/VoskNative.cs` — обёртка над C API libvosk (штатная портит кириллицу)
- `Services/VoiceGrammar.cs` — грамматика команд и названий программ
- `Services/VoiceCommandParser.cs` — разбор фразы в команду
- `Services/VoiceController.cs` — выполнение команды и подсказки на экране

Тесты: `dotnet test tests\Volumix.Tests` — разбор фраз и сквозная проверка (фраза озвучивается голосом
Microsoft Irina, распознаётся и разбирается).

## Сборка

Нужны .NET 8 SDK и Inno Setup 6 (`winget install JRSoftware.InnoSetup`).

```powershell
.\build.ps1
```

Результат: `dist\Volumix-Setup-1.2.0.exe`. Установка идёт для текущего пользователя, права администратора не нужны,
.NET встроен в exe.

Настройки хранятся в `%APPDATA%\Volumix\settings.json`, ошибки пишутся в `error.log` там же.

## Структура

- `src/Volumix/Services` — горячие клавиши, автозапуск, тема, трей, настройки, WinAPI
- `src/Volumix/ViewModels` — микшер (NAudio / Core Audio), каналы громкости, настройки
- `src/Volumix/Views` — главное окно, всплывающий микшер, индикатор громкости
- `installer/Volumix.iss` — скрипт установщика
- `tools/make-icon.ps1` — генерация иконки
